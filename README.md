# Unloop – Attention-Recovery App (PBL Prototype)

Interactive prototype for the PBL project **Doomscrolling and Low Attention Span Among Young Adults**.

## Features
- Daily short-form screen-time ring and per-app breakdown
- Scroll counter with a breathing-pause intervention
- Focus blocks (25 / 45 min) with streaks
- Weekly attention / sleep / study check-in
- Settings: daily limit, scroll threshold, watched apps, light/dark mode

## Run
Open `index.html` in any browser. No build step.

## Notes
Runs in the browser with sample data. Real app blocking needs Android UsageStatsManager and iOS Screen Time (Family Controls) in a React Native build.
